完成研修教材2026年10月7日

Oracle SQL演習教材 ― 自社の経費管理を題材に、1日で検証まで

資格試験の出題範囲16章を、架空の会社の経費精算で通して練習し、最後はビュー経由のアプリ開発演習へ。

処理の流れ

以前の困りごと

Oracle Database SQL（ORACLE MASTER Silver SQL）の範囲を一通り練習できる教材を、将来の研修の種として持っておきたい。市販の教科書は著作物なので、問題・データは自前で用意する必要があります。

取り組み

題材は自社の経費管理の列構成を参考にした架空の会社の経費精算にし、実在の店名や金額は使っていません。

16章の問題と解答SQL、章をまたぐ応用問題、本番用のビュー20本、ER図付きのスキーマ設計書、ビュー定義書、アプリ演習の要項と作成例、演習ユーザーと表を一括で作るスクリプトまでをそろえました。市販の教科書は「どの構文を扱うか」の一覧としてだけ参照し、文章・図・問題は複製していません。

結果

  • 解答SQL 402文がOracle Database 23ai Freeで全文実行できることを自動テスト（39件）で確認。ビュー・トリガーはすべて有効で、登録 → 提出 → 承認 → 支払の一周も通ります。
  • 着手から配布用zipの作成まで1日（2026年10月7日）。
  • 受講者のPCからの接続確認スクリプトと、サーバー側の整備スクリプトを同梱。

仕組みと体制

仕組み
Oracle Database 23ai Free（Oracle Linuxの仮想マシン）、Python（python-oracledb、pytest）、PowerShellの一括構築スクリプト
期間
2026年10月7日
体制
代表が題材とDB環境を決定、AIエージェント社員が問題・解答・ビュー・文書と検証
